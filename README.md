## ❓ Common project questions

### Can we work together in Turkish or English?

Yes. Harun Sekmen works with businesses in Türkiye and international teams. Project discussions and handover documentation can be in Turkish or English. See the [Turkish profile](README.tr.md) for local service details.

### Can AI or LLM features be part of a store project?

AI product search, catalog content and support assistants can be discussed as a separate integration scope. Catalog access, data handling, provider costs and human review need to be defined first. The eight repositories above focus on storefront and WooCommerce infrastructure prototypes.

### How do you assess performance and migration scope?

A WooCommerce speed project starts with measurements of the actual store. A Shopify to WooCommerce migration starts with a data and URL inventory. Hosting, extensions, product data and payment requirements determine the work and acceptance criteria.
