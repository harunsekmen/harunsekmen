I’m Harun Sekmen, an e-commerce developer focused on WordPress, WooCommerce and store integrations. I work with founders planning a new online store and teams improving an existing one. ## Open-source portfolio

These repositories contain **prototypes, plugin scaffolds and interface demos**. They show the code and design approach; a client deployment requires integration and validation for that store.

### Storefronts and design

- **[ApexCommerce](https://github.com/harunsekmen/apex-commerce-d2c-starter)** — A D2C storefront demo and WooCommerce starter scaffold exploring a cart drawer and sticky purchase bar.
- **[DawnTwin](https://github.com/harunsekmen/shopify-dawn-woocommerce-twin)** — A Dawn-inspired product page demo and WooCommerce plugin scaffold for a familiar shopping experience.
- **[FigmaToWoo](https://github.com/harunsekmen/figma-to-woo-blocks-system)** — E-commerce component experiments with comparison tables, FAQ layouts and shared design tokens.

### Cart, checkout and integrations

- **[Fast Fragments](https://github.com/harunsekmen/woo-fast-fragments)** — Browser-side cart fragment caching with a REST refresh endpoint.
- **[Checkout Guard](https://github.com/harunsekmen/woo-checkout-failover-guard)** — Checkout timeout notices and incident logging experiments.
- **[Database Vacuum](https://github.com/harunsekmen/woo-deadlock-vacuum)** — Batch cleanup experiments using WooCommerce Action Scheduler.
- **[HPOS Legacy Bridge](https://github.com/harunsekmen/woo-hpos-legacy-bridge)** — An experimental bridge between legacy postmeta calls and WooCommerce order storage.
- **[Webhook Resilience](https://github.com/harunsekmen/woo-webhook-resilience)** — Retry scheduling and a dead-letter queue prototype for failed webhook deliveries.

## Common project questions

### Can we work together in Turkish or English?

Yes. Project discussions and handover documentation can be in Turkish or English. See the [Turkish profile](README.tr.md) for services described for businesses in Türkiye.

### Can AI or LLM features be part of a store project?

Product search, catalog content and support assistants can be discussed as a separate integration scope. Catalog access, data handling, provider costs and human review need to be defined first. The eight repositories above focus on storefront and WooCommerce infrastructure prototypes.

### How do you assess performance and migration scope?

A speed project starts with measurements of the actual store. A migration starts with a data and URL inventory. Hosting, extensions, product data and payment requirements determine the work and acceptance criteria.
